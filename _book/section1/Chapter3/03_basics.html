Basic data processing in R

Generate datasets from vectors

The datasets are the two dimensional array whereas vectors are the one dimensional array. The vector is the fundamental data structure used to store the data of the same types. We can convert vectors to dataframe using data.frame( ) In order to create vectors, we can use some important functions like c( ), seq( ), and rep( ).

Lets create 3 vectors and combine them to create dataframe.

id <- 1:10
age<-c(34,45,32,56,54,67,65,89,23,34)
sex <- c(rep("Male",5), rep("Female",5))


dt<-data.frame(id, age, sex)

class(dt)
#> [1] "data.frame"

Data manipulation

Data manipulation in R involves various operations that transform and prepare data for analysis. The process includes tasks such as filtering rows, selecting variables, sorting, aggregating, merging, and reshaping data. In order to learn about data manipulation, lets explore mental health related data from Nepal Demographic and Health survey 2022 which is in the google drive.

4. Grouping: Another common operation in R is grouping. Grouping is where you split the data into groups based on one or more variables. Functions or summaries can then be applied to each group.

# Using base commands
lapply(split(data$PHQ9_Score, data$Sex), mean) # The split function groups the PHQ-9 score by sex and the lapply function is applied to calculate the mean PHQ-9 score for each sex

# Using dplyr
library(dplyr)
data |> 
  group_by(Sex) |> 
  summarise(AvgPHQ9 = mean(PHQ9_Score))

6. Conditional computing: There are various built-in functions in R and some come with specific packages, that facilitate conditional operations in R.

# Using base commands
data$depression.severity <- ifelse(data$PHQ9_Score >= 10, "Moderate to Severe", "None to Mild") # Creating a depression severity variable based on the variable PHQ9_score
table(data$depression.severity)
#> 
#> Moderate to Severe       None to Mild 
#>                530              11823
data$agecat <- ifelse(data$Age < 20, "15-19",
                      ifelse(data$Age >= 20 & data$Age <= 24, "20-24",
                             ifelse(data$Age >= 25 & data$Age <= 29, "25-29", 
                                    ifelse(data$Age >= 30 & data$Age <= 34, "30-34", 
                                           ifelse(data$Age >= 35 & data$Age <= 39, "35-39",
                                                  ifelse(data$Age >= 40 & data$Age <= 44, "40-44", "45-49"))))))
table(data$agecat)
#> 
#> 15-19 20-24 25-29 30-34 35-39 40-44 45-49 
#>  2390  2116  1900  1642  1629  1438  1238

8. Merging dataframes: Merging datasets is a fundamental task in data analysis, enabling res./0 earchers and analysts to combine different data sources into a single dataset for comprehensive analysis. Before diving into specific functions, it’s essential to understand some key concepts: a) Types of merge and b) key columns.

Types of Merges

  • Inner Join: Returns only the rows with matching values in both datasets.

  • Outer Join: Can be further classified into:

    • Full Outer Join: Returns rows with matching values and those that do not match, filling missing matches with NA.

    • Left Outer Join: Returns all rows from the left dataset and the matched rows from the right dataset. Rows in the left dataset without a match in the right dataset have NA for the right dataset’s columns.

    • Right Outer Join: Returns all rows from the right dataset and the matched rows from the left dataset. Rows in the right dataset without a match in the left dataset have NA for the left dataset’s columns.

  • Cross Join: Returns the Cartesian product of both datasets, combining each row of the first dataset with each row of the second dataset.

Key Columns

Key columns are the variables used to match rows between two datasets. It’s crucial that these variables have the same type (e.g., both are integers or both are character) and ideally have the same name in both datasets for ease of merging.

To learn about different dataset merging methods, lets create dummy data frames and practice.

7. Appending rows: Appending rows involves stacking datasets vertically, adding rows of one dataset below another. It is crucial that the datasets share the same structure, meaning they should have the same columns in the same order, and these columns should have compatible types across the datasets being combined. It requires a) Column Matching: The columns in the datasets must match in name and data type. If they do not match exactly, adjustments might be necessary before appending, and b) Order of Rows: The order in which datasets are appended can impact the analysis, especially if the data is time-sensitive.

8. Transforming datasets (wide to long or long to wide): The datasets can long or wide type based on the way it was collected or on the nature/layout of the questionnaire. In a wide-format dataset, each observation is represented by a single row, and different variables are stored in separate columns. This format is often easy to read but may become impractical when dealing with a large number of variables. In a long-format dataset, each observation is represented by multiple rows, and different variables are stored in a single column indicating the variable type. This format is more flexible and is often preferred for various analyses. Let’s see how they look like and practice conversions from long to wide format and vice-versa.

Wide to long transformation

# Using base commmands
# Create a wide-format data frame
wide_data <- data.frame(
  ID = c(1, 2, 3),
  Score_Math = c(85, 90, 78),
  Score_English = c(75, 80, 85)
)

# Convert to long format using reshape
long_data_base_wide_to_long <-reshape(
  wide_data, # The wide-format dataset to be reshaped
  direction = "long", # The direction of the reshaping, here "long"
  varying = 2:3, # Columns to be reshaped (in this case, columns 2 and 3)
  v.names = "Score", # The name for the new value column
  timevar = "Subject", # The name for the new variable column
  times = c("Math", "English")) # The values to be used in the new variable column
long_data_base_wide_to_long
#>           ID Subject Score id
#> 1.Math     1    Math    85  1
#> 2.Math     2    Math    90  2
#> 3.Math     3    Math    78  3
#> 1.English  1 English    75  1
#> 2.English  2 English    80  2
#> 3.English  3 English    85  3
# Using dplyr and tidyr
library(dplyr)
library(tidyr)

long_data_dplyr_wide_to_long <- wide_data |> 
  pivot_longer(cols = starts_with("Score"), # Columns to be reshaped (those starting with "Score")
    names_to = "Subject", # The name for the new variable column
    values_to = "Score") # The name for the new value column

9. Creating functions: Creating functions is a powerful method for encapsulating a series of actions, that promotes code organization, reusability, and readability. In data-centric tasks, functions become especially valuable for speeding up repetitive procedures like filtering, summarizing, or transforming datasets. Here’s a simple guide to creating functions in R and using them for data manipulations:

# Example 1: A function to calculate the mean of a vector
calculate_mean <- function(data) {
  result <- mean(data)
  return(result)
}

# Using the calculate_mean function created above
data <- c(1, 2, 3, 4, 5)
calculate_mean(data)
#> [1] 3
# Example 2: A function with parameters
multiply_numbers <- function(x, y) {
  result <- x * y
  return(result)
}

# Using the multiply_numbers function created above
multiply_numbers(1024, 88)
#> [1] 90112
# Example 3: Function to filter a data frame
filter_data <- function(df, condition) {
  result <- df[condition, ]
  return(result)
}

# Using the filter_data function created above
my_data <- data.frame(ID = 1:5, Value = c(10, 15, 8, 20, 12))
my_data
#>   ID Value
#> 1  1    10
#> 2  2    15
#> 3  3     8
#> 4  4    20
#> 5  5    12
filter_data(my_data, my_data$Value > 10)
#>   ID Value
#> 2  2    15
#> 4  4    20
#> 5  5    12
# Example 4: Function returning multiple values
calculate_stats <- function(data) {
  mean_val <- mean(data)
  sd_val <- sd(data)
  return(list(mean = mean_val, sd = sd_val))
}

# Using the calculate_stats function created above
my_data <- c(3, 6, 8, 12, 5)
calculate_stats(my_data)
#> $mean
#> [1] 6.8
#> 
#> $sd
#> [1] 3.420526

10. Using Loops: Loops are programming structures that allow you to repeat a block of code multiple times. They are essential for automating repetitive tasks and iterating over elements like vectors, lists, or data frames. Here are two primary types of loops in R and their common uses:

For Loop: The for loop is used when you know the number of iterations in advance. It iterates over a sequence (which can be a vector or a sequence generated by functions like seq()).

# Example: Printing numbers from 1 to 5 using a for loop
for (i in 1:5) {
  print(i)
}
#> [1] 1
#> [1] 2
#> [1] 3
#> [1] 4
#> [1] 5

While Loop: The while loop is used when you do not know the number of iterations in advance but have a condition that, when met, stops the loop.

# Example: Printing numbers from 1 to 5 using a while loop
i <- 1
while (i <= 5) {
  print(i)
  i <- i + 1
}
#> [1] 1
#> [1] 2
#> [1] 3
#> [1] 4
#> [1] 5

Loop control statements provide mechanisms to alter the flow of execution within loops. The break statement allows for the premature termination of a loop, while the next statement skips the remaining code for the current iteration and proceeds to the next iteration. These statements offer flexibility in managing loop execution based on specific conditions.

# Example: Using break and next in a for loop
for (i in 1:10) {
  if (i == 5) {
    break  # Exit the loop when i is 5
  }
  if (i %% 2 == 0) { # %% operator is the modulo operator. It returns the remainder of the division of one number by another.
    next  # Skip the rest of the code for even numbers
  }
  print(i)
}
#> [1] 1
#> [1] 3

Sometimes, a more functional programming approach is often preferred over explicit loops. Functions like apply, lapply, sapply, and mapplycan be used for looping over elements more efficiently.

# 'apply': Applies a function over the margins (rows or columns) of a matrix.
# Example: Sum of each column in a matrix
my_matrix <- matrix(1:9, ncol = 3)
my_matrix
#>      [,1] [,2] [,3]

#> [1]  6 15 24
# 'lapply': Applies a function to each element of a list.
# Example: Applying a function to each element of a list
my_list <- list(a = 1:3, b = 4:6, c = 7:9)
my_list
#> $a
#> [1] 1 2 3
#> 
#> $b
#> [1] 4 5 6
#>

lapply(my_list, function(x) x * 2)
#> $a
#> [1] 2 4 6
#> 
#> $b
#> [1]  8 10 12
#> 
#> $c
#> [1] 14 16 18

# Example: Simplifying the result of lapply into a vector
sapply(my_list, function(x) sum(x))
#>  a  b  c 
#>  6 15 24
