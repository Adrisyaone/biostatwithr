Learning Objectives

By the end of this chapter, you should be able to:

  1. Summarize categorical variables using frequencies and proportions.
  2. Summarize numeric variables using measures of central tendency, dispersion, and shape (skewness/kurtosis).
  3. Assess whether a numeric variable is approximately normally distributed.
  4. Produce cross-tabulations and stratified numeric summaries.
  5. Build a publication-ready “Table 1” using gtsummary.
  6. Visualize categorical and numeric data using base R and ggplot2.
  7. Produce a simple choropleth map using sf and ggplot2.

Part 1: Descriptive Statistics of Categorical Variables

The categorical variables can be described using frequency and percentage.

Frequency

We can use the table() function to generate a frequency table for categorical variables. The useNA argument controls whether missing values are shown: "no" (default), "ifany", or "always".

table(data$Sex)
#> 
#> Female   Male 
#>   7440   4913
table(data$Sex, useNA = "no")
#> 
#> Female   Male 
#>   7440   4913
table(data$Sex, useNA = "ifany")  # shows NA column only if missings exist
#> 
#> Female   Male 
#>   7440   4913
table(data$Sex, useNA = "always") # always shows NA column
#> 
#> Female   Male   <NA> 
#>   7440   4913      0

Proportion

To calculate proportions, use prop.table(), which is always applied on top of a table() object.

sex <- table(data$Sex)
prop.table(sex)
#> 
#>    Female      Male 
#> 0.6022828 0.3977172
# As percentage, rounded to 1 decimal
round(prop.table(sex) * 100, 1)
#> 
#> Female   Male 
#>   60.2   39.8
# Using the pipe (tidyverse loaded already)
100 * table(data$Sex) |>
  prop.table() |>
  round(3)
#> 
#> Female   Male 
#>   60.2   39.8

Central Tendency and Dispersion

mean(data$Age, na.rm = TRUE)
#> [1] 29.84554
sd(data$Age, na.rm = TRUE)
#> [1] 9.973959
var(data$Age, na.rm = TRUE)
#> [1] 99.47987
median(data$Age, na.rm = TRUE)
#> [1] 29
quantile(data$Age, probs = c(0.25, 0.5, 0.75), na.rm = TRUE)
#> 25% 50% 75% 
#>  21  29  38
min(data$Age, na.rm = TRUE)
#> [1] 15
max(data$Age, na.rm = TRUE)
#> [1] 49
range(data$Age, na.rm = TRUE)
#> [1] 15 49
# Mode (R has no built-in mode() for this purpose)
names(which.max(table(data$Age)))
#> [1] "18"
# Coefficient of variation — useful when comparing spread
# across variables measured on different scales
cv <- function(x) sd(x, na.rm = TRUE) / mean(x, na.rm = TRUE) * 100
cv(data$Age)
#> [1] 33.41859

mode() in base R does not compute the statistical mode — it returns the storage type of an object (numeric, integer, list, factor, etc.). Use the which.max(table(x)) approach shown above instead.

Shape of the Distribution: Skewness and Kurtosis

Mean and median alone can be misleading for skewed variables common in public health data (length of hospital stay, income, viral load). Skewness tells you about asymmetry; kurtosis tells you about “tailedness” relative to a normal distribution.

moments::skewness(data_new$age, na.rm = TRUE)
#> [1] 0.5263655
moments::kurtosis(data_new$age, na.rm = TRUE)
#> [1] 2.227403

Interpreting skewness:

  • ~0: roughly symmetric
  • > 0: right-skewed (long tail toward higher values) — mean > median
  • < 0: left-skewed (long tail toward lower values) — mean < median

Interpreting kurtosis: values close to 3 resemble a normal distribution (some packages report “excess kurtosis” centered at 0 — always check which convention your function uses).

Is the Variable Normally Distributed?

Whether a numeric variable is approximately normal informs later choices (e.g., parametric vs. non-parametric tests). Two common approaches:

# Visual check: Q-Q plot
qqnorm(data_new$age, main = "Q-Q Plot of Age")
qqline(data_new$age, col = "red", lwd = 2)
# Formal test (Shapiro-Wilk; sensitive with large n)
shapiro.test(data_new$age)
#> 
#>  Shapiro-Wilk normality test
#> 
#> data:  data_new$age
#> W = 0.93589, p-value < 2.2e-16

With large sample sizes, shapiro.test() will often reject normality even for minor, practically irrelevant deviations. Always pair the formal test with a visual check (histogram or Q-Q plot) and use judgment rather than relying on the p-value alone.

Histogram

hist(x, main = NULL, xlab = NULL, ylab = NULL, col = NULL, breaks = "Sturges", …)

hist(data$Age,
     main = "Distribution of Age", xlab = "Age", ylab = "Frequency",

# Overlay a normal curve for visual comparison
sequence <- seq(min(data$Age, na.rm = TRUE), max(data$Age, na.rm = TRUE), 1)

Part 4: Building a “Table 1” Summary Table

Nearly every public health manuscript opens with a baseline characteristics table stratified by exposure or outcome group — often called “Table 1.” The gtsummary package builds these in a few lines and produces output ready to export to Word.

table1 <- data |>
  select(Age, Sex, Ethnicity) |>
  tbl_summary(
    by = Sex,
    statistic = list(all_continuous() ~ "{mean} ({sd})",
                      all_categorical() ~ "{n} ({p}%)"),
    missing = "ifany"
  ) |>
  add_p() |>
  add_overall() |>
  modify_header(label ~ "**Variable**") |>
  bold_labels()

Part 5: Graphics with ggplot2

Base R plotting (Parts 1–3) is fast for exploratory data analysis. ggplot2 is generally the choice for publication-quality figures because of its consistent grammar and fine-grained control over every visual element — this section rebuilds several of the plots above using ggplot2.

Choosing a Chart Type

The right chart depends on your variable type and what you want to communicate:

  • Nominal (Sex, Ethnicity, Province): bar chart, pie chart, tree map
  • Ordinal (education level, Likert scale): ordered bar chart, dot plot
  • Interval/Ratio (Age, Height, Income): histogram, box plot, line chart
  • Time series: line chart, area chart
  • Hierarchical: treemap, sunburst chart
  • Correlation/Relationships: scatter plot, bubble chart, heatmap
  • Distribution: histogram, box plot, kernel density plot
  • Geospatial: choropleth map, cartogram
  • Comparison across groups: grouped or stacked bar chart

The Grammar of Graphics

Every ggplot2 plot has three required components:

  1. A dataset in tidy format.
  2. Aesthetic mappings between variables and visual properties (x, y, color, fill, shape, size).
  3. At least one layer (geom_*()) describing how observations are rendered — e.g. geom_bar(), geom_boxplot(), geom_histogram(), geom_point(), geom_line().

Basics

ggplot(data = data, aes(x = Sex, y = Age)) +
  geom_boxplot()
ggplot(data = data, aes(x = Sex, y = Age, fill = Ethnicity)) +
  geom_boxplot()
ggplot(data = data, aes(x = Sex, y = Age, fill = Ethnicity)) +
  geom_boxplot() +
  xlab("Gender") +
  ylab("Age (in years)") +
  labs(title = "Sex- and ethnicity-wise distribution of Age",
       subtitle = "Caption here", tag = "A")

Manual Colors

ggplot(data = data, aes(x = Sex, y = Age, fill = Ethnicity)) +
  geom_boxplot() +
  scale_fill_manual(values = c("lightpink", "lightblue", "lightyellow",
                                "lightgreen", "navy")) +
  xlab("Gender") + ylab("Age (in years)") +
  labs(title = "Sex- and ethnicity-wise distribution of Age")

Faceting

Faceting splits data into subsets and repeats the same plot for each — facet_wrap() (flexible grid) vs facet_grid() (strict grid).

ggplot(data = data, aes(x = Sex, y = Age, fill = Ethnicity)) +
  geom_boxplot() +
  facet_wrap(facets = ~Ethnicity, nrow = 3, scales = "free")

Themes

ggplot2 themes are built from four components: theme elements (e.g. panel.background, axis.title, legend.title), element functions (element_text(), element_line(), element_rect(), element_blank()), the theme() function to override defaults, and complete themes (theme_minimal(), theme_light(), theme_dark(), theme_classic()).

ggplot(data = data, aes(x = Sex, y = Age, fill = Ethnicity)) +
  geom_boxplot() +
  xlab("Gender") + ylab("Age (in years)") +
  labs(title = "Sex- and ethnicity-wise distribution of Age") +
  facet_wrap(facets = ~Ethnicity, nrow = 3, scales = "free_x") +
  theme(panel.background = element_rect(fill = "lightgreen"),
        panel.grid = element_blank(),
        plot.title = element_text(face = "bold", color = "red", size = 13),
        axis.title = element_text(face = "bold", color = "blue"),
        legend.position = "bottom")

Part 7: Applied Case Studies

The examples in this section use different datasets from the rest of the chapter (introduced individually below) to show how the tools above come together in real analysis workflows.

Case Study 1: 4+ ANC Visits by Province, with Confidence Intervals

Dataset: For graphics1.RDS — survey data with variables Province, Location, and Four_ANC (whether a woman had 4+ antenatal care visits).

dt <- readRDS(here("Environment/Datasets", "For graphics1.RDS"))

a <- dt |>
  group_by(Location, Province, Four_ANC) |>
  tally() |>
  ungroup() |>
  group_by(Location, Province) |>
  mutate(total = sum(n),
         percent = n / total * 100,
         ci = DescTools::BinomCI(n, total, method = "clopper-pearson") * 100) |>
  filter(Four_ANC == "Yes")

ggplot(data = a) +
  geom_bar(aes(x = Location, y = percent, fill = Location),
           col = "black", stat = "identity", alpha = 1) +
  geom_errorbar(aes(x = Location, y = percent,
                     ymin = a$ci[, 2], ymax = a$ci[, 3]),
                width = 0.3, linewidth = 1) +
  facet_wrap(~Province, nrow = 1) +
  geom_text(aes(x = Location, y = percent, label = sprintf("%0.2f", percent)),
            size = 4, vjust = 1.5, hjust = -0.1, angle = 90, col = "blue") +
  scale_fill_manual(values = c("pink", "lightgreen")) +
  xlab("Location") + ylab("Percent (%) with CI") +
  labs(title = "Distribution of 4+ ANC by Location and Province") +
  theme(panel.background = element_blank(),
        panel.grid = element_blank(),
        legend.position = "bottom")

Notice how the percent was calculated within Location and Province groups before faceting — a common pivot-table mistake is computing percentages over the wrong grouping level and only noticing once the bars don’t sum to 100% within each panel.
